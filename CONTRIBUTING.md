# Contributing

This SDK is generated and built in Whop's internal monorepo, and every commit on `main` here is a build
that monorepo pushes. Pull requests are turned off: a change made in this repository directly would be
replaced by the next build.

To report a bug, ask for something the SDK is missing, or suggest a change, [open an issue](../../issues/new).
Include the SDK version, a minimal example, and what you expected to happen.
